## Description

Follow-up release after 0.8.0. Closes the load-path half of the ID uniqueness work that 0.8.0 only closed on the creation path, extends the response-detail parameter to the one verbose tool 0.8.0 missed, and settles the API-shape inconsistencies from the 2026-07-28 field report section 6.

0.8.0 was itself a breaking release (summary-by-default responses, allowed filesystem roots, model-wide ID uniqueness). The parameter and field renames here are the breaking half of section 6 — their additive halves could ship in a patch, so anything in this milestone that only needs an alias does not have to wait for it.
